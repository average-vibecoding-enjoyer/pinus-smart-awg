# Одноразовый импорт Pinus Preview

Подготовлен код и патч. На действующий сервер/бот ничего не установлено; реальные профили и база бота не открывались этим модулем.

## Контракт

Бот проверяет владельца и действующий доступ перед выдачей. Ссылка: `https://YOUR-HOST/pinus/import#token=…`. Токен — 256 случайных бит, срок не более 300 секунд. В базе хранится SHA-256 токена и зашифрованный AES-GCM профиль. Новая ссылка аннулирует предыдущую ссылку этого профиля. Атомарная транзакция выдаёт содержимое только одному запросу.

Клиент после подтверждения сервера делает `POST /api/pinus/import` с `Authorization: Bearer TOKEN` и пустым телом. Успех: JSON `{"version":1,"name":"PROFILE","config":"WG_QUICK_TEXT"}`. Повтор/истечение: HTTP 410; перенаправления запрещены. Части URL после `#` не передаются браузером серверу. Страница не должна подключать аналитику, сторонние скрипты или переносить фрагмент в query.

Токен погашается при получении, до подтверждения добавления профиля в клиенте. Если пользователь отменил добавление, он запрашивает новую ссылку у бота. Новый профиль не запускается автоматически. Исполняемые hooks в удалённом профиле запрещены клиентом.

## Установка на отдельный тестовый сервер

1. Создать отдельное окружение Python 3.11+ и установить `requirements.txt`. Сгенерировать отдельный случайный 32-байтовый ключ импорта, сохранить в файле с правами 0600; ключ не является ключом VPN.
2. Разместить key-file и SQLite в каталоге с правами 0700, доступном только выделенному сервисному пользователю. Бот и HTTP-процесс должны иметь согласованный доступ. Не использовать существующую VPN-базу для токенов.
3. Запустить `pinus_import.py --db /PROTECTED/import.sqlite --key-file /PROTECTED/import.key --origin https://YOUR-HOST`. Слушатель доступен только на `127.0.0.1:9073`.
4. Перед ним настроить HTTPS reverse proxy с корректным сертификатом. Для `/api/pinus/import` разрешить только POST, ограничить частоту и число соединений, размер запроса и таймауты; отключить access log этого location и кэширование; не логировать Authorization. Нельзя открывать внутренний HTTP-порт наружу.
5. Применить `pinusvpn_bot-import.patch` к тестовой копии бота. `integration-base.json` содержит SHA-256 файла, на котором подготовлен патч. Проверить `git apply --check` прежде применения. Существующая отправка файла остаётся.
6. Задать только в тестовом окружении бота `PINUS_IMPORT_ORIGIN`, `PINUS_IMPORT_DB`, `PINUS_IMPORT_KEY_FILE`, `PINUS_IMPORT_PROFILE_ROOT`. При отсутствии ORIGIN функция выключена. PROFILE_ROOT — существующий разрешённый каталог `.conf`; symlink за его пределы отклоняется.
7. При отзыве доступа пользователя также вызывать `store.revoke(tg_id)`. Патч уже отзывает токены при удалении профиля; точки смены подписки зависят от серверной версии. До подключения этого хука ранее выданная ссылка может жить до конца своих 5 минут. Проверка доступа выполняется при выдаче, а не повторно HTTP-процессом при получении.

Пример ограничений в конфигурации reverse proxy — параметры выбрать по нагрузке тестовой системы:

```nginx
# http context:
limit_req_zone $binary_remote_addr zone=pinus_import:1m rate=5r/s;
limit_conn_zone $binary_remote_addr zone=pinus_import_conn:1m;

# Inside the existing HTTPS server for YOUR-HOST:
location = /api/pinus/import {
    limit_except POST { deny all; }
    limit_req zone=pinus_import burst=10 nodelay;
    limit_conn pinus_import_conn 4;
    client_max_body_size 1k;
    proxy_read_timeout 10s;
    proxy_connect_timeout 2s;
    proxy_pass http://127.0.0.1:9073;
    access_log off;
    proxy_no_cache 1;
    add_header Cache-Control no-store always;
}
```

## Проверка

`python -m unittest -v` использует исключительно временную синтетическую SQLite-базу. Проверены конкурирующие запросы, повтор, истечение, обновление/отзыв токена, шифрование содержимого и отказ чужому/неавторизованному владельцу до чтения файла. Тесты не импортируют бот и не запускают HTTP-сервис. Патч бота проверен синтаксически, без выполнения.

Проверки HTTPS reverse proxy, Telegram-доставки, отзыва подписки и реального импорта через развёрнутую инфраструктуру остаются обязательными перед включением этой функции на рабочем сервере.
