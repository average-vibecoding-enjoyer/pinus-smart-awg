# Security-аудит Pinus Smart AWG 3.2.2

Дата проверки: 2026-07-11.

## Что проверено

- GUI-клиент и Windows manager: `client/`;
- manager/core: `core/`;
- smart-routing engine: закреплённый `amnezia-box` commit
  `f40548f91a14582975096d0310e3c6afd44656f8` с опубликованным патчем;
- Go 1.26.5 и `govulncheck` 1.6.0;
- release-сборка x64, ARM64 и x86.

Сборочный скрипт запускает `govulncheck` как обязательный release gate. Для
каждого из трёх модулей результат одинаковый:

```text
Your code is affected by 0 vulnerabilities.
This scan also found 0 vulnerabilities in packages you import.
```

## Известное предупреждение уровня модуля

Подробный режим дополнительно сообщает `GO-2026-5932`: пакет
`golang.org/x/crypto/openpgp` признан устаревшим и небезопасным по конструкции.
Исправленной версии для этого пакета нет.

Pinus Smart AWG не импортирует `openpgp`. Модуль `golang.org/x/crypto` нужен
приложению для `blake2b`, `blake2s` и `curve25519`. Поэтому `govulncheck`
классифицирует запись только как присутствующую в требуемом модуле и отдельно
подтверждает ноль уязвимостей в импортируемых пакетах и ноль достижимых
уязвимостей. Это предупреждение нельзя честно исправить обновлением версии или
скрыть без удаления реально нужных криптографических пакетов.

## Цепочка поставки

- версия Go закреплена в `.go-version`;
- версия `govulncheck`, архив Go, исходный commit engine, патч и результат
  `go.sum` закреплены в `build-public-release.ps1`;
- release публикует исходный архив engine, применённый патч,
  `release-manifest.json` и `SHA256SUMS.txt`;
- CI проверяет tracked-файлы на VPN-ключи, токены, платёжные секреты,
  приватные сертификаты и DPAPI-хранилища собственным локальным скриптом;
- каталоги пресетов применяются только после проверки Ed25519-подписи,
  строгой схемы и монотонной ревизии;
- приватный ключ подписи не хранится в репозитории и защищён Windows DPAPI.

GitHub Dependabot анализирует версии модулей, а не достижимость функций. Поэтому
его число alerts может быть больше результата `govulncheck`. После обновления
основной ветки устаревшие alerts закрываются автоматически; предупреждение без
исправленной версии следует оценивать по импортам и достижимости, как описано
выше.
