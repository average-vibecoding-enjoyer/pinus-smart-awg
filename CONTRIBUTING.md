# Contributing

1. Создайте отдельную ветку.
2. Не добавляйте VPN-профили, runtime-конфиги, журналы и реальные адреса
   пользователей.
3. Запустите `go test ./...` отдельно в `client/` и `core/`.
4. Для изменений сборки проверьте хотя бы
   `.\build-public-release.bat -Architectures amd64`.
5. Опишите поведение, риск и способ проверки в pull request.

Сохраняйте существующие MIT/SPDX-заголовки и атрибуцию upstream-проектов.
Изменения GPL-движка должны публиковаться вместе с соответствующими исходниками.
