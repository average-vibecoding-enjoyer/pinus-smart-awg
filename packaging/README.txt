PINUS SMART AWG 3.2.3

Получить VPN-профиль: https://t.me/pinusvpn_bot

1. Распакуйте архив в обычную папку. Не запускайте EXE прямо из ZIP.
2. Запустите PinusSmartAWG.exe.
3. При первом запуске Windows запросит права администратора для установки
   отдельной службы Pinus Smart AWG. Рабочая копия клиента и проверенного
   сетевого движка будет установлена в защищённую папку Program Files.
4. Импортируйте профиль .conf или .zip на странице «Профили».
5. Выберите профиль и режим маршрутизации, затем нажмите большую кнопку.

В папке должны лежать программа, движок, Wintun и лицензионные файлы:

- PinusSmartAWG.exe
- amnezia-box.exe
- wintun.dll
- LICENSE.txt
- ENGINE-LICENSE.txt
- WINTUN-LICENSE.txt
- THIRD-PARTY-NOTICES.txt

Закрытие окна сворачивает приложение в трей и не отключает VPN. Команда
«Выход» в меню трея останавливает VPN и завершает службу клиента.

Профили, правила и логи хранятся локально. Диагностика в приложении не копирует
приватные ключи.

Для обновления распакуйте новый архив и запустите новый PinusSmartAWG.exe.
После подтверждения UAC клиент обновит менеджер в отдельной версионной папке
Program Files. Уже работающий туннель продолжит держать соединение до следующего
осознанного переподключения.
