# Security Policy

Не публикуйте сведения об уязвимости, приватные VPN-профили, ключи или журналы
в открытых GitHub Issues.

Отправьте описание проблемы в поддержку: https://t.me/MEN9_HET

Полезно приложить:

- версию Pinus Smart AWG и архитектуру Windows;
- краткие шаги воспроизведения;
- ожидаемое и фактическое поведение;
- минимальный журнал без приватных ключей и персональных данных.

Секреты из профиля `.conf` перед отправкой необходимо удалить. Не отправляйте
`PrivateKey`, `PresharedKey`, пароли, токены и платёжные ключи.

Сетевой каталог пресетов проверяется встроенным публичным ключом Ed25519,
ревизией и строгой схемой до записи в кеш или применения. Сообщайте отдельно,
если клиент принял неподписанный каталог, откат ревизии, повтор ревизии с иным
содержимым либо опасное имя системного процесса.
