# Changelog

Все заметные изменения публичных версий Pinus Smart AWG документируются здесь.

## [3.3.3 Preview] - 2026-09-21

Первый публичный выпуск ветки Preview объединяет изменения 3.3.0–3.3.3. Пакеты Windows x64 собраны 2026-09-14; публикация не меняет их бинарники.

### Соединения и протоколы

- добавлена поддержка AWG 3.1 в нативном и выборочном режимах с сохранением старых профилей WireGuard/AWG 1.x–2.x;
- ядро `amneziawg-go/v3 v3.1.20260828` закреплено по commit и контрольным суммам; исправлены потеря первого пакета при изменении S4 и проверка длин CPS;
- в 3.3.2 исправлен DNS прямых исходящих соединений: `direct` явно использует `direct-dns` вместо унаследованного DNS через AWG;
- в 3.3.3 добавлен ограниченный повтор TCP по IPv4 через тот же AWG, если IPv6-подключение вернуло ошибку недоступности сети и известно имя сайта; DNS повтора также идёт через VPN;
- исправлены ошибки проверки CIDR и IPv6 endpoint, восстановления после сетевых событий, синхронизации callback/таймеров, переключения профилей и освобождения ресурсов; добавлена проверка конфигурации до переключения без запуска TUN.

### Маршрутизация и интерфейс

- в режиме «Весь интернет» добавлены VK и «Белые списки», изначально включённые; в режиме «Только выбранное» они изначально выключены;
- включено означает VPN, выключено — прямой маршрут; выбор сохраняется отдельно для каждого режима;
- группа VK включает домены `.ru`/`.com`, узлы медиа и звонков; «Белые списки» объединяют конечный набор популярных российских сервисов;
- пользовательские правила имеют приоритет перед VK, российской группой и общим маршрутом;
- с 3.3.1 изменения применяются сразу к активному профилю: раздел «Управление», фиксация подключения и отдельное обязательное применение удалены;
- добавлены объяснение маршрута, история настроек, зашифрованные резервные копии, поиск и клавиатурная навигация.

### Диагностика и обслуживание

- диагностика различает наличие туннеля и результат проверки трафика; краткий копируемый отчёт исключает данные профиля;
- добавлены резервные профили и явная настройка блокировки интернета при сбое Preview;
- добавлен импорт по одноразовой HTTPS-ссылке с просмотром профиля; серверный модуль поставляется отдельно;
- Preview использует отдельные службы, данные и MSI UpgradeCode относительно основной ветки; установка новой Preview обновляет существующую Preview и требует перезапуска.

### Проверка и ограничения

Пройдены тесты клиента, `go vet`, проверки конфигураций, регрессии DNS/IPv4-повтора и тесты протокольной совместимости в памяти. Подтверждение исправления в пользовательском браузере, WFP при сбое, MSI на чистой VM и реальные звонки/стриминг VK остаются отдельными проверками. Переключение правил пересоздаёт туннель. Повтор IPv4 не применяется к UDP, неизвестному имени, IPv6-only сайтам или ошибкам уже установленного соединения. Сборка не подписана и опубликована как предварительный релиз.

## [3.2.5] - 2026-07-11

### Маршрутизация

- исправлена гонка при изменении или удалении правил во время активного VPN:
  старый smart engine больше не может удалить runtime-конфиг нового запуска;
- runtime-конфиги теперь создаются отдельно для каждого поколения engine и
  очищаются только породившим их процессом;
- supervisor отслеживает только реальные интерфейсы с активным default route и
  больше не принимает изменения Radmin, Hyper-V, Teredo, VirtualBox или
  собственного TUN за смену физической сети;
- добавлен регрессионный тест горячего перезапуска smart routing.

## [3.2.3] - 2026-07-11

### Установщик

- исправлена ложная ошибка MSI «Windows 10 or later is required» на Windows
  10/11: Windows Installer намеренно сообщает для них устаревший `VersionNT`;
- проверка совместимости теперь читает реальный `CurrentBuildNumber` из реестра
  и требует Windows 10 build 10240 или новее;
- release pipeline проверяет версию MSI и точное условие запуска после сборки.

## [3.2.2] - 2026-07-11

Релиз стабильности, восстановления и защиты цепочки поставки.

### Стабильность

- smart routing автоматически восстанавливается после сна, смены Wi-Fi/LTE,
  исчезновения сети, падения `amnezia-box` и перезапуска manager-службы;
- добавлены ограниченные повторные попытки без бесконечного частого рестарта;
- переключение нескольких AWG-профилей стало последовательным: новый профиль
  запускается только после полной остановки остальных;
- доменные endpoint теперь разрешаются с тайм-аутом, предпочтением IPv4 и
  безопасным fallback на IPv6;
- IPv4-only, IPv6-only и dual-stack профили получают явную DNS/route policy без
  тихого выхода неподдерживаемой семьи адресов мимо full-tunnel VPN.

### Безопасность

- Go обновлён до 1.26.5, уязвимые `golang.org/x/*` зависимости обновлены во всех
  трёх модулях; `govulncheck` включён как обязательный release gate;
- `go vet` и локальный скан tracked-файлов на VPN-ключи, токены, платёжные
  секреты, сертификаты и DPAPI-хранилища добавлены в CI и release pipeline;
- сборка `amnezia-box` закреплена по commit, патчу, `go.sum` и SHA-256;
- менеджер получил Windows SCM recovery и зависимости от сетевого стека;
- пресеты маршрутизации обновляются только после Ed25519-подписи, строгой
  валидации, проверки ревизии и защиты от rollback/revision reuse;
- локальный ключ подписи пресетов хранится отдельно и защищён Windows DPAPI.

### Диагностика

- добавлена безопасная компонентная проверка manager, профиля, DNS endpoint,
  engine SHA, TUN, физических интерфейсов, конфликтов профилей и пресетов;
- отчёт копируется без `PrivateKey` и `PresharedKey`, а кнопка логов больше не
  открывает каталог с runtime-конфигом.

## [3.2.1] - 2026-07-11

Первый публичный beta-релиз.

### Добавлено

- современный Windows-интерфейс управления AmneziaWG;
- режимы всего трафика через VPN и только выбранного трафика;
- исключения напрямую для приложений, доменов и IP/CIDR;
- готовые правила для Discord, YouTube, Telegram, Instagram и AI-сервисов;
- выбор приложения из списка запущенных процессов;
- импорт `.conf` и ZIP-профилей;
- автоматическое переключение профилей без отдельной кнопки применения;
- единый интерфейс основного окна и компактных диалогов;
- MSI и portable-сборки для x64, ARM64 и x86;
- воспроизводимая сборка закреплённого `amnezia-box` и проверенного Wintun;
- автоматические CI и GitHub Releases.

### Безопасность

- зависимости проверяются по SHA-256 перед запуском;
- приватные профили и runtime-данные исключены из репозитория;
- удаление MSI очищает службы приложения, сохраняя зашифрованные профили для
  безопасной переустановки.
