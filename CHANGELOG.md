# Changelog

Все заметные изменения публичных версий Pinus Smart AWG документируются здесь.

## [3.2.1] - 2026-07-11

### Добавлено

- ссылка на Telegram-бот [@pinusvpn_bot](https://t.me/pinusvpn_bot) в README;
- отдельные действия «Импортировать» и «Купить профиль» на пустой странице
  профилей;
- ссылка на команду Pinus VPN в окне «О приложении»;
- безопасный режим предпросмотра пустого списка профилей для визуальной
  проверки интерфейса.

### Изменено

- окно «О приложении» полностью переведено на общий сглаженный интерфейс
  мини-окон Pinus Smart AWG;
- технические сведения собраны в компактную карточку, а ссылка на Telegram
  оформлена как полноценная акцентная кнопка.

## [3.2.0] - 2026-07-11

Первая публичная beta.

### Добавлено

- современный Windows-интерфейс управления AmneziaWG;
- режимы всего трафика через VPN и только выбранного трафика;
- исключения напрямую для приложений, доменов и IP/CIDR;
- готовые правила для Discord, YouTube, Telegram, Instagram и AI-сервисов;
- выбор приложения из списка запущенных процессов;
- импорт `.conf` и ZIP-профилей;
- MSI и portable-сборки для x64, ARM64 и x86;
- воспроизводимая сборка закреплённого `amnezia-box` и проверенного Wintun;
- автоматические CI и GitHub Releases.

### Безопасность

- зависимости проверяются по SHA-256 перед запуском;
- приватные профили и runtime-данные исключены из репозитория;
- удаление MSI очищает службы приложения, сохраняя зашифрованные профили для
  безопасной переустановки.
