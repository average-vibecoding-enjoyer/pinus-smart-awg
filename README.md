## Что нового

- **AWG 3.1 в обоих режимах.** Импорт `.conf` и ZIP с профилями сохраняет совместимость с WireGuard и AWG 1.x–2.x. Сервер должен поддерживать параметры выбранного профиля.
- **VK и «Белые списки».** Включённый сервис идёт через VPN, выключенный — напрямую. В режиме «Весь интернет» оба переключателя изначально включены; в режиме «Только выбранное» — выключены. Выбор сохраняется отдельно для каждого режима. «Белые списки» — конечная группа популярных российских сервисов.
- **Применение сразу.** Изменения режима, сервисов и правил применяются к активному профилю без отдельного подтверждения. Раздел «Управление» и обязательная кнопка «Применить» удалены. Пользовательские правила имеют приоритет перед группами сервисов.
- **Исправления соединений.** Прямой трафик использует явно выбранный прямой DNS. В Smart-режиме при ошибке недоступности IPv6-сети TCP-подключение с известным именем сайта может повториться по IPv4 через тот же AWG и его DNS.
- **Инструменты профиля.** История маршрутизации, зашифрованные резервные копии с паролем, объяснение маршрута, поиск, диагностика трафика, резервные профили и отдельная настройка блокировки интернета при сбое Preview.
- **Надёжность.** Исправлены ошибки проверки конфигураций, восстановления соединения, обработки сетевых событий и переключения профилей. Добавлен клиент импорта по одноразовой HTTPS-ссылке; [серверный модуль](server-preview/README.md) поставляется отдельно и требует настройки.

## Установка и статус Preview

У Preview отдельные службы, каталог данных и идентификатор MSI. Она устанавливается рядом с основной веткой Pinus, но обновление **уже установленной Preview** заменяет её файлы и требует перезапуска подключения. Пока работает другая служба Pinus, Preview не подключается. Даже комплект из portable ZIP использует службу Windows при обычном запуске. Публикация на GitHub сама по себе ничего не устанавливает и не переключает.

Пакеты собраны **14 сентября 2026 года**; опубликованы **21 сентября 2026 года** как предварительный релиз. Клиент и MSI без цифровой подписи, поэтому Windows может показать предупреждение SmartScreen.

Пройдены тесты клиента, `go vet`, проверки синтетических конфигураций и регрессии DNS/IPv4-повтора на настоящем коде движка с соединениями в памяти. Есть тесты обмена зашифрованными пакетами ядер WireGuard/AWG. Эти проверки не подтверждают работу всех сайтов в реальной сети.

- Переключение маршрутов по-прежнему пересоздаёт туннель и может кратко прервать соединение.
- Повтор по IPv4 обрабатывает конкретную ошибку установления TCP-соединения. Он не исправляет серверный IPv6, UDP, IPv6-only сайты и случаи без доступного имени сайта, в том числе некоторые соединения с ECH.
- Итоговое устранение `ERR_CONNECTION_RESET` в браузере, звонки и стриминг VK, защита WFP при сбое и установка на чистой VM требуют отдельной проверки. Группа российских сервисов не гарантирует доступ при ограничениях мобильного оператора.

## Исходники и сборка

Исходники AWG находятся в `third_party/amneziawg-go-v3`; версия и контрольные суммы закреплены в `third_party/AWG3-PIN.json`. Движок amnezia-box собирается из закреплённого commit с патчем `engine/amnezia-box-security.patch`. В релиз включены соответствующие исходники готовых бинарников.

Сборка x64: `./build-public-release.ps1 -Architectures amd64`. Скрипт создаёт файлы и MSI, но не устанавливает их; проверки реальной сети и драйверов по умолчанию выключены. Демонстрация интерфейса без подключения: `PinusSmartAWG.exe /preview`.

Клиент и ядро AWG распространяются под MIT, изменённый amnezia-box — под GPL-3.0-or-later, Wintun — на условиях отдельной лицензии в комплекте. [Публикация релиза](PUBLISHING.md) · [Историческая документация 3.2.5](docs/README-3.2.5-HISTORICAL.md)
