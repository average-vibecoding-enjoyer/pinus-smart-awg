# Pinus Smart AWG 3.3.0 Preview

Изолированное обновление Windows-клиента Pinus на базе 3.2.5. Основная установленная версия и её VPN-соединение не изменялись.

[Изменения, результаты проверок и ограничения](docs/UPDATE-3.3.0-PREVIEW.md).

- AWG 3.1 в обоих режимах и совместимость старых `.conf`.
- VK и популярные российские сервисы, согласованные маршруты и DNS.
- Фиксация соединения, явное применение, история, зашифрованные копии, объяснение маршрута.
- Диагностика, явная защита при сбое, резервные профили, поиск и клавиатура.
- Клиент одноразового импорта и [отдельный серверный модуль](server-preview/README.md).

Preview использует отдельные службы `PinusAWGPreview*`, каталоги `PinusSmartAWGPreview`, папку установки и MSI UpgradeCode. Пока работает другая служба Pinus, Preview отказывается подключаться. Для сетевых испытаний нужен отдельный компьютер/VM и тестовый профиль. Установка и реальные сетевые сценарии этой сборки ещё не проверены.

Исходники нового ядра: `third_party/amneziawg-go-v3`; исходный commit, контрольные суммы и локальный патч закреплены в `third_party/AWG3-PIN.json` и `engine/amneziawg-go-v3.patch`. Движок amnezia-box собирается из указанного в `build-public-release.ps1` commit с приложенным патчем. Поддержка AWG 3.1 в клиенте не обновляет VPN-сервер автоматически.

Сборка x64: `./build-public-release.ps1 -Architectures amd64`. Скрипт собирает файлы и MSI, не устанавливает их. Проверки реальной сети и драйверов по умолчанию выключены. Полные соответствующие исходники движка и клиента распространяются вместе с пакетами.

Демонстрация интерфейса без сети: `PinusSmartAWG.exe /preview`.

Историческая документация 3.2.5 сохранена в `docs/README-3.2.5-HISTORICAL.md`.
